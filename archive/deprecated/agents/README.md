# Deprecated Agents

이 디렉터리는 현재 활성 LangGraph 플로우에서 사용하지 않는 이전 도메인별 에이전트 구현을 보관합니다.

현재 활성 에이전트는 `src/agents/`의 다음 5개 노드입니다.

- `supervisor.py`
- `researcher.py`
- `analyst.py`
- `reviewer.py`
- `synthesis.py`

아래 파일들은 참고용으로 보관하며 `src/graph.py`에서 import하지 않습니다.

- `company_profile.py`
- `financial_analysis.py`
- `credit_analysis.py`
- `investment_metrics.py`
- `employee_review.py`
