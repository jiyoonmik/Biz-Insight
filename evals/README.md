# Evals

멀티에이전트 파이프라인에서 "고쳤더니 좋아졌다"는 감각은 신뢰할 수 없다. 프롬프트
한 줄을 바꾸면 리포트 전체가 달라 보이고, 두 리포트를 눈으로 비교하면 대체로
방금 고친 쪽이 나아 보인다. 그래서 재현 가능한 측정 두 가지를 둔다.

## 설계 원칙: LLM을 채점자로 쓰지 않는다

LLM-as-judge를 붙이면 채점자 자신이 흔들려서, 점수 변화가 **파이프라인이 좋아진
것**인지 **채점자가 그날 후하게 군 것**인지 구분할 수 없다. 회귀 측정이 목적이므로
같은 입력에 같은 점수가 나오는 것만 잰다.

대신 이렇게 나눴다.

| | 재는 것 | 방법 |
|---|---|---|
| 잴 수 있는 것 | 라우팅 도메인, 리포트 수치의 근거 일치, 구조 요건, 실행 경로 | 결정론적 코드 |
| 못 재는 것 | 해석의 설득력, 문장 품질 | 사람이 읽는다 (자동화하지 않음) |

## Tier 1 — 라우팅 평가 (CI 게이트)

```bash
uv run python -m evals.run_routing_eval
uv run python -m evals.run_routing_eval --verbose            # 불일치 상세
uv run python -m evals.run_routing_eval --min-exact-match 0.9
```

- 데이터셋: `datasets/routing.jsonl` (32건)
- LLM 호출 없음. Supervisor가 규칙 기반이라 가능하다 — 라우터를 LLM으로 만들었다면
  이 평가는 매번 돈과 시간이 들고 결과도 흔들렸을 것이다.
- 지표: 도메인 집합 완전 일치율, 평균 자카드, 도메인별 precision/recall/F1
- `tests/test_routing_eval_gate.py`가 같은 평가를 테스트로도 묶어 둔다.

### 이 평가가 실제로 잡아낸 결함

평가셋을 먼저 쓰고 돌렸더니 완전 일치율이 **87.5%**였고, 실패 4건이 우연이 아니라
두 가지 결함이었다.

1. **일반 명사가 도메인을 확정했다.** "이 회사 어때?"의 '회사', "투자해도 될까?"의
   '투자'가 각각 `overview`, `investment`를 단독으로 트리거해, 종합 판단을 원한
   요청이 단일 도메인으로 좁혀졌다. → 약한 신호(`WEAK_DOMAIN_KEYWORDS`)를 분리해
   라우팅 결정에서 제외하고, 약한 신호뿐이면 전체 도메인으로 확장하도록 변경.
2. **ASCII 키워드가 부분문자열로 걸렸다.** `per`가 `performance`에 매칭되어
   "analyze financial performance"가 `investment`로도 분류됐다. → ASCII 키워드는
   단어 경계로 매칭하고 한글은 조사 때문에 부분문자열 매칭을 유지.

수정 후 **100%**. 다만 이 데이터셋은 내가 의도한 정책을 인코딩한 것이므로,
100%는 "라우터가 완벽하다"가 아니라 "알려진 회귀가 없다"는 뜻이다.

## Tier 2 — 리포트 평가 (수동)

```bash
uv run python -m evals.run_report_eval --dry-run   # LLM 없이 데이터셋/라우팅 점검
uv run python -m evals.run_report_eval --limit 2   # 실제 실행 (GOOGLE_API_KEY 필요)
```

- 데이터셋: `datasets/reports.jsonl` (KOSDAQ 성장기업 5 + KOSPI 2)
- 실제로 그래프를 돌리므로 API 키와 시간이 든다. CI 게이트가 아니라 변경 전후
  비교용이다.
- 채점 항목:
  - **근거 대조율** — Verifier가 계산한 값. 리포트 본문 수치 중 도구가 실제로
    반환한 값과 일치한 비율. 정확도가 아니라 대조 가능성 지표다. 원장 값에서
    계산된 파생 수치(증감률 등)는 미확인으로 잡히는 것이 정상이다.
  - **구조 요건 충족률** — Synthesis 프롬프트의 작성 지침과 1:1로 대응하는 정규식
    점검(stock_code, 기준연도, SWOT, 리스크 섹션 등). 지침을 넣어 두고 지켜졌는지
    재지 않으면 프롬프트는 조용히 무너진다.
  - **실행 지표** — 에이전트 경로, 도구 호출 수, 원장 수집량, 재검토 발생 여부,
    errors, 소요 시간
- 결과는 `results/`에 JSON으로 남는다 (git 추적 제외).
